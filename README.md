# Social Media Sentiment Analysis & NLP Analytics

A Natural Language Processing (NLP) and sentiment analysis project focused on mining social media text data to extract public opinion trends and emotional polarity.

---

## 📌 Project Overview
Social media platforms generate vast amounts of unstructured text data containing valuable insights into public perception, brand feedback, and audience emotion. This project applies Natural Language Processing workflows to clean, process, and analyze social media posts—classifying user sentiments and highlighting key thematic trends through text analytics.

---

## 📊 Dataset
* **Source:** [Social Media Sentiments](https://www.kaggle.com/datasets/kashishparmar02/social-media-sentiments-analysis-dataset) 

---

## 🛠️ Tools & Libraries
* **Language:** Python
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Natural Language Processing:** NLTK, TextBlob / VADER
* **Data & Text Visualization:** Matplotlib, Seaborn, WordCloud
* **Environment:** Jupyter Notebook / Google Colab

---

## 🚀 Execution Workflow

1. **Text Preprocessing & Cleaning:** Standardized unstructured text data by removing noise (URLs, punctuation, special characters, and numbers) and filtering out standard stopwords.
2. **Sentiment Scoring & Polarity Assessment:** Applied VADER/TextBlob rule-based lexicon models to compute continuous sentiment polarity scores for each post.
3. **Classification & Categorization:** Segmented social media posts into discrete sentiment buckets: **Positive**, **Negative**, and **Neutral**.
4. **Visual Analytics & WordCloud Generation:** Constructed frequency distribution charts and sentiment-segmented word clouds to identify recurring vocabulary across emotional categories.

---

## 📈 Deliverables & Outputs
* **Analysis Notebook:** Fully annotated Python notebook documenting the end-to-end NLP and sentiment scoring pipeline.
* **Distribution Charts:** Bar graphs and pie charts illustrating overall sentiment proportions across the dataset.
* **WordCloud Visualizations:** High-density word clouds displaying top keywords associated with positive, negative, and neutral posts.
* **Insights Summary:** Executive summary detailing key themes and audience sentiment patterns.

---

## 🎯 Key Insights & Applications
* **Public Perception Trends:** Quantified the overall sentiment distribution to gauge general audience polarity.
* **Keyword Drivers:** Identified high-frequency emotional triggers and topical vocabulary driving negative or positive posts.
* **Real-World Impact:** Demonstrates how automated NLP pipelines can support social listening, brand perception monitoring, and public feedback tracking.
