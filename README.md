# Cognetix_Social-Media-Sentiment-Analysis
# Social Media Sentiment Analysis

## 📌 Objective
Analyze public sentiment from social media posts using NLP techniques.

## 📊 Dataset
- Source: [Social Media Sentiments](https://www.kaggle.com/datasets/kashishparmar02/social-media-sentiments-analysis-dataset)

## 🛠️ Tools & Libraries
- Python, Pandas, NLTK, TextBlob/VADER, Matplotlib, Seaborn

## 🚀 Steps
1. Load and clean text data (remove stopwords, punctuation, URLs).
2. Apply sentiment scoring (VADER/TextBlob).
3. Classify posts as Positive, Negative, Neutral.
4. Visualize sentiment distribution (bar/pie/wordcloud).
5. Summarize insights.

## 📈 Deliverables
- Sentiment analysis notebook
- Distribution charts
- Wordcloud visualization
- Insights summary
